# Cypher the product depends on

All queries live in `core/*.py`, are parameterised, and are executed through `Org.read` (`GRAPH.RO_QUERY`)
or `Org.write`. Every API response includes a `trace` with the exact queries that produced it, which is
what the UI's **Show Cypher** panel displays.

## The five queries that matter most

**1. Hybrid recall, step 1: vector candidates, with visibility enforced in the graph** (`recall.vector_candidates`)
```cypher
CALL db.idx.vector.queryNodes('Task','embedding',$n,vecf32($emb)) YIELD node AS t, score
WITH t, 1 - score AS sim WHERE sim >= $min_sim
MATCH (s:Solution)-[:SOLVES]->(t)
MATCH (s)<-[:PRODUCED]-(:Session)<-[:RAN]-(a:Dev)-[:MEMBER_OF]->(at:Team)
MATCH (v:Dev {name:$viewer})-[:MEMBER_OF]->(vt:Team)
WHERE s.visibility = 'org' OR (s.visibility = 'team' AND at = vt) OR a = v
RETURN t.id AS task_id, t.text AS task_text, sim, s.id AS solution_id, s.status AS status
```

**2. Hybrid recall, step 2: walk past stale fixes to the newest one** (`recall.supersede_walk`)
```cypher
UNWIND $ids AS sid
MATCH (s0:Solution {id:sid})
OPTIONAL MATCH p = (newer:Solution)-[:SUPERSEDES*1..4]->(s0)
WITH s0, p ORDER BY length(p) DESC
WITH s0, collect(p)[0] AS longest
RETURN s0.id AS id,
       CASE WHEN longest IS NULL THEN [s0.id] ELSE reverse([n IN nodes(longest) | n.id]) END AS chain
```

**3. Change impact: who breaks if this component changes, and who is live on it right now** (`notice.impact` + `notice.live_sessions`)
```cypher
MATCH (c:Component {name:$c})
MATCH p = (dep:Component)-[:DEPENDS_ON*1..3]->(c)        // depth validated in code, then inlined (FalkorDB can't parameterise it)
WITH dep, p ORDER BY length(p)
WITH dep, collect(p)[0] AS p
OPTIONAL MATCH (t:Team)-[:OWNS]->(dep)
RETURN dep.name AS component, length(p) AS depth, [n IN nodes(p) | n.name] AS chain, t.name AS owner
```

**4. Routing a question to whoever is live on the relevant component** (`route.live_on_components`)
```cypher
UNWIND $comps AS cw MATCH (c:Component {name:cw.name})
MATCH (d:Dev)-[:RAN]->(s:Session {status:'live'})-[:TOUCHES]->(c)
WHERE s.last_seen >= $since AND d.name <> $asker
MATCH (d)-[:MEMBER_OF]->(t:Team)
RETURN d.name AS dev, t.name AS team, s.id AS sid, s.task AS task, c.name AS component, cw.w AS w
```

**5. Expertise authority: PageRank over who credits whom** (`brain.pagerank`)
```cypher
CALL algo.pageRank('Dev','CREDITS') YIELD node, score RETURN node.name AS dev, score
```
`CREDITS` edges are written whenever someone reuses your fix successfully or your answer resolves their question.

## Every query the product runs (generated by `scripts/gen_cypher_doc.py`)

### `session.start`
```cypher
MATCH (d:Dev {name:$dev}), (t:Task {id:$task_id})
                 MERGE (s:Session {id:$sid})
                 SET s.agent=$agent, s.status=$status, s.started_at=$at, s.last_seen=$at,
                     s.task=$task, s.attempts=coalesce(s.attempts,0), s.tokens=coalesce(s.tokens,0)
                 MERGE (d)-[:RAN]->(s)
                 MERGE (s)-[:WORKED_ON]->(t)
                 WITH s UNWIND $components AS cn
                 MATCH (c:Component {name:cn}) MERGE (s)-[:TOUCHES]->(c)
```

### `session.project`
```cypher
MATCH (s:Session {id:$sid}) MERGE (p:Project {name:$project})
                     MERGE (s)-[:IN_PROJECT]->(p)
```

### `recall.vector_candidates`
```cypher
CALL db.idx.vector.queryNodes('Task','embedding',$n,vecf32($emb)) YIELD node AS t, score
                       WITH t, 1 - score AS sim WHERE sim >= $min_sim
                       MATCH (s:Solution)-[:SOLVES]->(t)
                       MATCH (s)<-[:PRODUCED]-(:Session)<-[:RAN]-(a:Dev)-[:MEMBER_OF]->(at:Team)
                       MATCH (v:Dev {name:$viewer})-[:MEMBER_OF]->(vt:Team)
                       WHERE s.visibility = 'org' OR (s.visibility = 'team' AND at = vt) OR a = v
                       RETURN t.id AS task_id, t.text AS task_text, sim, s.id AS solution_id, s.status AS status
                       ORDER BY sim DESC
```

### `recall.supersede_walk`
```cypher
UNWIND $ids AS sid
                       MATCH (s0:Solution {id:sid})
                       OPTIONAL MATCH p = (newer:Solution)-[:SUPERSEDES*1..4]->(s0)
                       WITH s0, p ORDER BY length(p) DESC
                       WITH s0, collect(p)[0] AS longest
                       RETURN s0.id AS id,
                              CASE WHEN longest IS NULL THEN [s0.id]
                                   ELSE reverse([n IN nodes(longest) | n.id]) END AS chain
```

### `recall.expand`
```cypher
UNWIND $ids AS sid
                       MATCH (s:Solution {id:sid})<-[:PRODUCED]-(se:Session)<-[:RAN]-(a:Dev)-[:MEMBER_OF]->(tm:Team)
                       OPTIONAL MATCH (se)-[:IN_PROJECT]->(p:Project)
                       OPTIONAL MATCH (s)-[:TAUGHT]->(l:Lesson)
                       WITH s, se, a, tm, p, collect(DISTINCT {text:l.text, kind:l.kind}) AS lessons
                       OPTIONAL MATCH (s)-[:FAILED_WITH]->(e:Error)
                       WITH s, se, a, tm, p, lessons, collect(DISTINCT e.signature) AS errors
                       OPTIONAL MATCH (s)-[:HIT]->(h:Error)
                       WITH s, se, a, tm, p, lessons, errors, collect(DISTINCT h.signature) AS hit
                       OPTIONAL MATCH (s)-[:BUILDS_ON]->(b:Solution)
                       WITH s, se, a, tm, p, lessons, errors, hit, collect(DISTINCT {id:b.id, title:b.title}) AS builds_on
                       OPTIONAL MATCH (:Session)-[r:REUSED]->(s)
                       WITH s, se, a, tm, p, lessons, errors, hit, builds_on,
                            sum(CASE WHEN r.outcome IN ['reused','worked'] THEN 1 ELSE 0 END) AS reuse_ok
                       OPTIONAL MATCH (s)-[:SOLVES]->(t:Task)
                       RETURN s.id AS id, s.title AS title, s.summary AS summary, s.code AS code,
                              s.status AS status, s.effort_minutes AS effort_minutes, s.attempts AS attempts,
                              s.tokens_spent AS tokens_spent, s.visibility AS visibility, s.created_at AS created_at,
                              se.id AS session_id, se.started_at AS session_started,
                              a.name AS author, tm.name AS team, p.name AS project,
                              lessons, errors, hit, builds_on, reuse_ok,
                              t.id AS task_id, t.text AS task_text
```

### `presence.overlap_candidates`
```cypher
MATCH (me:Session {id:$sid})-[:WORKED_ON]->(t:Task)
                       MATCH (me)<-[:RAN]-(md:Dev)-[:MEMBER_OF]->(mt:Team)
                       CALL db.idx.vector.queryNodes('Task','embedding',10,t.embedding) YIELD node AS ot, score
                       WITH me, md, mt, ot, 1 - score AS sim WHERE sim >= $min_sim
                       MATCH (other:Session {status:'live'})-[:WORKED_ON]->(ot)
                       WHERE other <> me AND other.last_seen >= $since
                       MATCH (other)<-[:RAN]-(od0:Dev) WHERE od0 <> md
                       MATCH (other)<-[:RAN]-(od:Dev)-[:MEMBER_OF]->(otm:Team)
                       RETURN DISTINCT other.id AS session_id, od.name AS dev, otm.name AS team,
                              other.task AS task, sim, otm <> mt AS cross_team,
                              other.started_at AS started_at
                       ORDER BY sim DESC LIMIT 5
```

### `presence.link_overlaps`
```cypher
MATCH (me:Session {id:$sid}) UNWIND $others AS o
                     MATCH (s:Session {id:o.id})
                     MERGE (me)-[r:OVERLAPS]->(s) SET r.score = o.sim, r.at = $at
```

### `presence.live`
```cypher
MATCH (d:Dev)-[:RAN]->(s:Session {status:'live'})
                       WHERE s.last_seen >= $since
                       MATCH (d)-[:MEMBER_OF]->(t:Team)
                       OPTIONAL MATCH (s)-[:TOUCHES]->(c:Component)
                       WITH s, d, t, collect(DISTINCT c.name) AS components
                       OPTIONAL MATCH (s)-[o:OVERLAPS]-(s2:Session {status:'live'})<-[:RAN]-(d2:Dev)-[:MEMBER_OF]->(t2:Team)
                       RETURN s.id AS id, s.task AS task, s.agent AS agent, s.started_at AS started_at,
                              s.last_seen AS last_seen, d.name AS dev, t.name AS team, components,
                              collect(DISTINCT CASE WHEN s2 IS NULL THEN NULL ELSE
                                {session_id:s2.id, dev:{name:d2.name, team:t2.name}, task:s2.task, score:o.score} END) AS overlaps
                       ORDER BY started_at DESC
```

### `inbox.questions`
```cypher
MATCH (asker:Dev)-[:ASKED]->(q:Question {status:'routed'})-[r:ROUTED_TO]->(x)
                            WHERE (x:Session AND x.id = $sid) OR (x:Dev AND x.name = $dev)
                            MATCH (asker)-[:MEMBER_OF]->(at:Team)
                            RETURN q.id AS question_id, q.text AS text, asker.name AS asker, at.name AS asker_team,
```

### `inbox.notices`
```cypher
MATCH (by:Dev)-[:ANNOUNCED]->(n:Notice)-[r:DELIVERED_TO]->(x)

                          MATCH (n)-[:AFFECTS]->(c:Component)
```

### `memory.save_solution`

### `memory.reuse`
```cypher
MATCH (se:Session {id:$sid})<-[:RAN]-(me:Dev), (s:Solution {id:$sol})
                        MATCH (s)<-[:PRODUCED]-(:Session)<-[:RAN]-(author:Dev)
                        MERGE (se)-[r:REUSED]->(s)
                        SET r.at=$at, r.outcome=$outcome,
                            r.tokens_saved = toInteger(coalesce(s.tokens_spent, 0) * 0.8)
                        WITH me, author, r, s WHERE me <> author
                        MERGE (me)-[c:CREDITS]->(author) SET c.count = coalesce(c.count, 0) + 1
                        RETURN r.tokens_saved AS tokens_saved, author.name AS author, s.title AS title
```

### `memory.failed`
```cypher
MATCH (s:Solution {id:$sol}), (se:Session {id:$sid})<-[:RAN]-(d:Dev)
                 MERGE (e:Error {signature:$err})
                 MERGE (s)-[f:FAILED_WITH]->(e) SET f.at=$at, f.by=d.name
                 SET s.status = CASE s.status WHEN 'superseded' THEN 'superseded' ELSE 'broken' END
                 MERGE (se)-[r:REUSED]->(s) SET r.at=$at, r.outcome='failed', r.tokens_saved=0
```

### `lineage.chain`
```cypher
MATCH (s:Solution {id:$id})
                       OPTIONAL MATCH up = (s)-[:BUILDS_ON|SUPERSEDES*1..6]->(anc:Solution)
                       WITH s, collect(up) AS ups
                       OPTIONAL MATCH down = (desc:Solution)-[:BUILDS_ON|SUPERSEDES*1..6]->(s)
                       WITH s, ups, collect(down) AS downs
                       UNWIND (ups + downs + [null]) AS p
                       WITH s, p WHERE p IS NOT NULL
                       UNWIND relationships(p) AS r
                       WITH DISTINCT startNode(r) AS a, endNode(r) AS b, type(r) AS rel
                       RETURN a.id AS from_id, b.id AS to_id, rel
```

### `lineage.nodes`
```cypher
UNWIND $ids AS i MATCH (s:Solution {id:i})<-[:PRODUCED]-(se:Session)<-[:RAN]-(d:Dev)-[:MEMBER_OF]->(t:Team)
                       OPTIONAL MATCH (se)-[:IN_PROJECT]->(p:Project)
                       RETURN s.id AS id, s.title AS title, s.status AS status, s.created_at AS created_at,
```

### `brain.helped`
```cypher
MATCH (d:Dev)-[:MEMBER_OF]->(t:Team)
                       OPTIONAL MATCH (other:Dev)-[c:CREDITS]->(d)
                       RETURN d.name AS dev, t.name AS team, coalesce(sum(c.count), 0) AS helped
```

### `brain.at_risk`
```cypher
MATCH (s:Solution {status:'active'})<-[:PRODUCED]-(:Session)<-[:RAN]-(d:Dev)-[:MEMBER_OF]->(t:Team)
                                 WHERE s.effort_minutes >= 240
                                 OPTIONAL MATCH (other:Session)-[:REUSED]->(s)
                                 OPTIONAL MATCH (other)<-[:RAN]-(od:Dev) WHERE od <> d
                                 WITH s, d, t, count(DISTINCT od) AS others
                                 WHERE others = 0
                                 RETURN s.id AS id, s.title AS title, d.name AS dev, t.name AS team,
                                        s.effort_minutes AS effort, s.attempts AS attempts
                                 ORDER BY effort DESC LIMIT $k
```

### `brain.savings`
```cypher
MATCH (d:Dev)-[:RAN]->(:Session)-[r:REUSED]->(:Solution)
                       WHERE r.outcome IN ['reused','worked']
                       MATCH (d)-[:MEMBER_OF]->(t:Team)
                       RETURN t.name AS team, sum(r.tokens_saved) AS tokens_saved, count(r) AS reuses
                       ORDER BY tokens_saved DESC
```

### `brain.help_flows`
```cypher
MATCH (a:Dev)-[c:CREDITS]->(b:Dev)
                       MATCH (a)-[:MEMBER_OF]->(ta:Team), (b)-[:MEMBER_OF]->(tb:Team)
                       WHERE ta <> tb
                       RETURN tb.name AS from_team, ta.name AS to_team, sum(c.count) AS count
                       ORDER BY count DESC
```
